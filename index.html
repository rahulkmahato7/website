M.Tech Thesis

DISSERTATION · M.TECH · MICROELECTRONICS & VLSI

Design and Simulation of FeFET-Based 8-Bit CIM Array MAC Operations

Rahul Kumar Mahato (24534010)  ·  Supervised by Prof. Sudeb Dasgupta & Dr. Sourajeet Roy  ·  Dept. of ECE, IIT Roorkee — 2026

This dissertation tackles the Memory Wall: the growing energy and latency cost of shuttling data between memory and compute in conventional von Neumann systems, which dominates the power budget of edge AI inference. It investigates Compute-in-Memory (CIM) as an alternative, progressing from digital Boolean logic in SRAM to fully analog Multiply-Accumulate (MAC) computation in emerging non-volatile memory.

The work is split into two design studies. The first is a Dual-Port 8T SRAM-based Boolean in-memory computing cell that performs NAND, NOR, XOR, and XNOR directly on the bitlines of a conventional SRAM cell — without extra memory cells or shared read bitlines — verified through transistor-level simulation in Cadence Virtuoso.

The core contribution is an 8×8 FeFET-based analog CIM array for 8-bit MAC operations, targeting edge AI inference. Built on GlobalFoundries' 28 nm HKMG process with a silicon-doped hafnium oxide (Si:HfO₂) ferroelectric gate stack, each FeFET stores a non-volatile binary weight as a threshold-voltage state. The design encodes 8-bit inputs as Pulse-Width Modulated (PWM) signals across four sequential cycles, and combines partial products in the charge domain using a hierarchical 1C-2C-4C capacitive shift-and-add network — cutting the required ADC count by 50% versus a conventional multi-cycle approach. A five-cycle bipolar wake-up protocol conditions each cell before a state-setting pulse locks in the weight, and a non-disturbing 100 mV read preserves polarization during inference.

Simulated in Cadence Virtuoso using a BSIM + Verilog-A compact model of FeFET ferroelectric hysteresis, the array achieves, under nominal conditions (VDD = 1.0 V, 27°C, typical corner):

8.59TOPS/W energy efficiency
2.13GOPS throughput
98µW average power
16ns latency / cycle

Together, these results show that FeFET non-volatility, near-zero standby leakage, and analog in-memory dot-product execution offer a meaningful efficiency advantage over SRAM-based CIM designs for 8-bit neural network inference at the edge.
